Configuración de Correo (SMTP)

Parámetros del servidor para el envío de notificaciones por correo

Servidor
Para Gmail usa una contraseña de aplicación (no tu contraseña normal), generada en tu cuenta de Google con verificación en 2 pasos activa.
Se avisa a los responsables cuando a una tarea le falten estos días (o menos) para vencer. 0 = avisar solo el mismo día.
Probar Envío

Envía un correo de prueba con la configuración guardada para verificar que todo funciona.

Valores recomendados para Gmail:

  • Servidor: smtp.gmail.com
  • Puerto: 465 con SSL (o 587 con STARTTLS)
  • Usuario: tu dirección de Gmail completa
  • Contraseña: una contraseña de aplicación de 16 caracteres
